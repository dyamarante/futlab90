# FutLab 90

**Futebol visto pelo tempo.**

Projeto hobby e independente para análise estatística de jogadores de futebol.

## Estrutura

- `index.html` — home do FutLab 90, com a marca e o seletor de atletas.
- `jogadores/lorran/index.html` — Estudo 01: Lorran, Monitoramento Estatístico Pós-Copa.
- `assets/` — marca vetorial do FutLab 90.
- `marca.html` — prancha visual da marca.
- `vercel.json` — configuração para publicação estática no Vercel.

## Próximos jogadores

Crie uma nova pasta em `jogadores/<slug-do-atleta>/` e adicione o card correspondente à grade da home.
